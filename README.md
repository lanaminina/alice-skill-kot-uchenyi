# Навык Алисы: Кот Ученый (ChatBook Tutor)

MVP голосового навыка для Яндекс Диалогов на базе FastAPI и YandexGPT Lite. Навык реализует литературный разбор школьной классики (Тьютор) в двух режимах:
1. **Вопрос-ответ** — прямой ответ на вопросы по тексту.
2. **Сократический диалог** — обучающий режим, где навык задает наводящие вопросы по таксономии Блума, не давая готовых ответов.

В навык встроена базовая логика монетизации (freemium): после 5 реплик пользователю предлагается оформить подписку "Чатбук Плюс", и сессия завершается.

## Технический стек
- **Фреймворк:** FastAPI (асинхронная обработка для укладки в лимит 4.5 сек Алисы)
- **Модель:** YandexGPT Lite (через прямой асинхронный REST API вызов `httpx`)
- **Состояние:** Механизмы Алисы `session_state` (текущий диалог) и `user_state` (вечные лимиты юзера).

## Быстрый старт (Локальное тестирование)

### 1. Установка зависимостей
Убедитесь, что у вас установлен Python 3.9+.
```bash
cd alice-skill-kot-uchenyi
pip install -r requirements.txt
```

### 2. Настройка ключей Yandex Cloud
1. Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
2. Откройте `.env` и впишите туда ваши учетные данные Yandex Cloud:
- `YANDEX_API_KEY` — API-ключ сервисного аккаунта с правами на вызов YandexGPT.
- `YANDEX_FOLDER_ID` — ID каталога в Yandex Cloud.

### 3. Запуск сервера
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Сервер запустится на `http://localhost:8000/webhook`.

### 4. Проброс туннеля (Ngrok)
Яндекс Диалогам нужен публичный HTTPS URL. Запустите ngrok:
```bash
ngrok http 8000
```
Скопируйте полученный HTTPS URL (например, `https://abcdef123.ngrok.app`) — к нему нужно добавить суффикс `/webhook`. Итоговый адрес: `https://abcdef123.ngrok.app/webhook`.

## Настройка в консоли Яндекс Диалогов

1. Перейдите в [Консоль разработчика Яндекс Диалогов](https://dialogs.yandex.ru/developer/).
2. Создайте новый диалог типа **Навык в Алисе**.
3. Укажите название: **Кот Ученый** (и активационные имена, например, "литературный разбор").
4. В разделе **Backend** выберите "Webhook URL" и вставьте ссылку от ngrok (`https://.../webhook`).
5. Сохраните настройки.

## Тестирование
Сразу после сохранения вы можете открыть вкладку **Тестирование** в консоли Диалогов.
Напишите "Привет" или "Запусти навык Кот Ученый". 
Навык должен ответить стартовым сообщением и предложить на выбор 3 книги:
- Гранатовый браслет
- Вишневый сад
- Гроза

Для проверки обработки таймаута (если Yandex Cloud отвечает дольше 3.5 сек), навык штатно перехватит ошибку и вернет фоллбэк: *"Мяу... Я глубоко задумался. Задайте этот вопрос ещё раз, пожалуйста."*

## Сброс лимитов при тесте
Если вы исчерпали 5 бесплатных запросов при тестировании, вам нужно либо сменить аккаунт Яндекса, либо временно увеличить `FREE_LIMIT` в файле `main.py` (и сервер перезапустится сам).
